# Imported models

Generated by `art/blender/build_models.py`. Previews are in `art/previews/`, and the editable source is `art/blender/lake_models.blend`.

The game runs without these models. Until they're imported it uses simple block versions.

## Import once in Studio (about 10 minutes)

1. In ReplicatedStorage, create a Folder named **Assets**, and a Folder named **Fish** inside it.
2. For each file in this folder, open **File → Import 3D** (or Avatar/Home tab → Import 3D):
   - In the importer, check that the size looks right. The rowboat is about 11 studs long and the cabin is about 21 studs wide. If the size is off, change the importer's scale/unit setting to studs.
   - Import, then move the new Model into **ReplicatedStorage/Assets**.
   - Keep the file name as the model name: `Rowboat`, `DockSection`, `Cabin`, `Tree`, `TreeRound`.
3. Do the same for `Fish/*.fbx` into **ReplicatedStorage/Assets/Fish**. Keep the names `perch`, `bass`, `trout`, `pike`, `catfish`.
4. Save the place. Rojo leaves `Assets` alone; it only manages `ReplicatedStorage.Shared`.

Colors don't come from the files. The game paints each part by its name (Hull, Trim, Log, Back, Fin, ...) using `game/src/shared/Config/Palette.luau`. That way the same pieces can be recolored for each region.

## Changing a model

Edit `art/blender/build_models.py` (shapes or `PALETTE`), then run:

```
& "$env:LOCALAPPDATA\Programs\Blender\Blender Foundation\Blender 5.3\blender.exe" -b --factory-startup --python art/blender/build_models.py
```

This rewrites the FBX files, the previews, the `.blend` and `Palette.luau`. Then re-import any models that changed.
